# Forge 1.19.2 port

This branch ports the complete Forge renderer from ACowAdonis/voxy commit 8285ecccf3d296f40d9b500a70aab2ca90affe2a to Minecraft 1.19.2, Forge 43.5.2, and Java 17.

The port must preserve persistent formats, coordinate packing, voxel and mip layouts, renderer inputs, configuration defaults, and lifecycle semantics. Loader- and Minecraft-version-specific adapters may differ.
